# Code of Conduct

HTMLslide is an open-source project for local-first, agent-assisted presentation workflows. We want issues, pull requests, discussions, and reviews to stay useful, respectful, and safe for contributors and users.

## Expected Behavior

- Be respectful and constructive in technical disagreement.
- Keep feedback focused on the work, the evidence, and the user impact.
- Assume good intent while still being clear about bugs, risks, and security boundaries.
- Respect privacy. Do not post private decks, API keys, provider tokens, personal data, or logs that expose them.
- Help keep contribution paths accessible to new contributors by explaining required context and test evidence.

## Unacceptable Behavior

- Harassment, threats, insults, or sustained personal attacks.
- Sexualized, discriminatory, or exclusionary language or imagery.
- Publishing another person's private information without explicit permission.
- Posting or requesting secrets, credentials, private deck contents, or exploit details in public issues.
- Deliberately disrupting issues, pull requests, CI, releases, or maintainer workflows.

## Scope

This code applies in project spaces, including GitHub issues, pull requests, discussions, reviews, documentation, release notes, and community channels connected to HTMLslide.

## Reporting

For conduct concerns, contact the maintainers through the private channel listed in the GitHub repository. For exploitable security issues, use GitHub private vulnerability reporting instead of a public issue.

Maintainers may remove content, close issues or pull requests, restrict participation, or escalate to GitHub moderation when needed to protect contributors and users.

## Enforcement Principles

Maintainers should respond proportionally, document decisions when appropriate, and prioritize user safety, contributor safety, and the integrity of the project.
