# Code of Conduct

HTMLslide contributors are expected to keep project spaces respectful, constructive, and safe for users who may be working with private deck content or provider credentials.

## expected behavior

- Keep disagreement technical and evidence-based.
- Respect privacy and never post private decks, API keys, provider tokens, or logs that expose them.
- Help contributors understand the relevant product plan, specs, tests, and security boundaries.

## unacceptable behavior

- Harassment, threats, insults, or sustained personal attacks.
- Discriminatory or exclusionary language or imagery.
- Publishing another person's private information without permission.
- Posting secrets, credentials, private deck contents, or exploit details in public issues.
- Deliberately disrupting issues, pull requests, CI, releases, or maintainer workflows.

## reporting

For conduct concerns, contact the maintainers through the private channel listed in the GitHub repository. For exploitable vulnerabilities, use GitHub private vulnerability reporting instead of a public issue.
